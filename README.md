# 📚 Cursos Escola - API REST (Django)

API REST para o gerenciamento de cursos, módulos, disciplinas e alunos, desenvolvida com **Django** e **Django REST Framework (DRF)**.

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Framework Web:** Django
- **Toolkit de API:** Django REST Framework (DRF)
- **Banco de Dados:** SQLite *(ou PostgreSQL / MySQL)*
- **Autenticação:** JWT (SimpleJWT) / Token Auth
- **Documentação:** drf-spectacular / drf-yasg *(Swagger/ReDoc)*
